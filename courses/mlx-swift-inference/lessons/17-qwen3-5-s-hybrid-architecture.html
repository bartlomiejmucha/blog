17. Qwen3.5's hybrid architecture

Three of every four Qwen3.5 layers drop softmax attention for Gated DeltaNet, a linear attention whose memory is a fixed-size matrix. Implement it with plain ops, then as a custom Metal kernel, and implement the gated full-attention layers in between.

By the end of this lesson you can

  • Explain linear attention and why its state does not grow with context
  • Derive the gated delta rule update the code implements
  • Implement the short causal convolution and its cache
  • Write the recurrence as a Metal kernel and measure the gain
  • List every way a Qwen3.5 checkpoint differs from Qwen3 when loading

Why a hybrid

Softmax attention's cache grows with every token, and each decode step reads all of it. At long context the cache, not the weights, dominates memory and bandwidth (Lesson 9). Linear attention replaces the growing list of keys and values with a fixed-size summary, updated once per token. It is cheaper but loses some ability to recall exact details from far back.

Qwen3.5 mixes the two: of its 24 layers, 18 are Gated DeltaNet (linear) and 6 are full softmax attention, in a repeating pattern of three linear layers then one full. The full-attention layers keep precise long-range recall; the linear layers make everything else cheap. For the 0.8B model, the KV cache is 12 KB per token instead of the 112 KB of Qwen3-0.6B, plus about 19 MB of fixed state.

The gated delta rule

Each linear-attention head keeps a matrix S of shape [Dv, Dk] (128×128 here), an associative memory that maps keys to values. For each token, with key k, value v and query q:

S ← g · S                      decay: forget a little of everything (0 < g < 1)
S ← S + β · (v − S k) kᵀ        delta rule: move what S returns for k toward v
y = S q                        read: what does the memory say for this query?

The middle line is the "delta" in DeltaNet. S k is what the memory currently returns for key k; the update writes only the difference between that and the true value, scaled by a write strength β. Plain linear attention would add v kᵀ blindly and pile up interference; the delta rule corrects instead. The decay g lets the model forget stale content. Both are computed per token and per head from the input:

g = exp(−exp(A_log) · softplus(a + dt_bias))     a = in_proj_a(x),  learned A_log, dt_bias
β = sigmoid(b)                                   b = in_proj_b(x)

The plain-ops implementation is a direct transcription, compiled into one kernel per step:

code/Sources/Inference/GatedDelta.swiftswift
/// One step of the gated delta rule for every head at once.
///
///     S = g * S                      decay the memory
///     S = S + k * beta * (v - S k)   write v at key k, correcting what was there
///     y = S q                        read the memory with the query
///
/// Shapes: q, k `[B, H, Dk]`, v `[B, H, Dv]`, g and beta `[B, H]`,
/// state `[B, H, Dv, Dk]` in float32.
let gatedDeltaStep = compile(shapeless: true) { (args: [MLXArray]) -> [MLXArray] in
    let (q, k, v, g, beta) = (args[0], args[1], args[2], args[3], args[4])
    var state = args[5] * g[.ellipsis, .newAxis, .newAxis]
    let kvMemory = (state * k[.ellipsis, .newAxis, 0...]).sum(axis: -1)
    let delta = (v - kvMemory) * beta[.ellipsis, .newAxis]
    state = state + k[.ellipsis, .newAxis, 0...] * delta[.ellipsis, .newAxis]
    let y = (state * q[.ellipsis, .newAxis, 0...]).sum(axis: -1)
    return [y.asType(q.dtype), state]
}
code/Sources/Inference/GatedDelta.swiftswift
/// Runs the recurrence over `T` tokens with plain MLX ops, one step at a
/// time. Returns outputs `[B, T, Hv, Dv]`, the final state, and the state
/// after every token (used to roll back rejected speculative tokens).
func gatedDeltaOps(
    q: MLXArray, k: MLXArray, v: MLXArray, g: MLXArray, beta: MLXArray, state: MLXArray
) -> (MLXArray, MLXArray, [MLXArray]) {
    let T = q.dim(1)
    var state = state
    var ys = [MLXArray]()
    var states = [MLXArray]()
    for t in 0 ..< T {
        let r = gatedDeltaStep([q[0..., t], k[0..., t], v[0..., t], g[0..., t], beta[0..., t], state])
        ys.append(r[0])
        state = r[1]
        states.append(state)
    }
    return (stacked(ys, axis: 1), state, states)
}

The state is kept in float32. It accumulates thousands of small updates, and bfloat16's three significant digits would erode it.

The full layer

code/Sources/Inference/Qwen35.swiftswift
/// Gated DeltaNet: linear attention whose state is a fixed-size matrix per
/// head instead of a growing list of keys and values.
final class GatedDeltaNet: Module {
    let numKHeads: Int
    let numVHeads: Int
    let headKDim: Int
    let headVDim: Int
    let keyDim: Int
    let valueDim: Int
    let convDim: Int
    let convKernel: Int

    @ModuleInfo(key: "in_proj_qkv") var inProjQKV: Linear
    @ModuleInfo(key: "in_proj_z") var inProjZ: Linear
    @ModuleInfo(key: "in_proj_b") var inProjB: Linear
    @ModuleInfo(key: "in_proj_a") var inProjA: Linear
    @ModuleInfo(key: "conv1d") var conv1d: Conv1d
    @ModuleInfo(key: "norm") var norm: GatedRMSNorm
    @ModuleInfo(key: "out_proj") var outProj: Linear
    @ParameterInfo(key: "A_log") var aLog: MLXArray
    @ParameterInfo(key: "dt_bias") var dtBias: MLXArray

    init(_ c: Qwen35Config) {
        numKHeads = c.linearNumKeyHeads
        numVHeads = c.linearNumValueHeads
        headKDim = c.linearKeyHeadDim
        headVDim = c.linearValueHeadDim
        keyDim = numKHeads * headKDim
        valueDim = numVHeads * headVDim
        convDim = 2 * keyDim + valueDim
        convKernel = c.linearConvKernelDim

        _inProjQKV.wrappedValue = Linear(c.hiddenSize, convDim, bias: false)
        _inProjZ.wrappedValue = Linear(c.hiddenSize, valueDim, bias: false)
        _inProjB.wrappedValue = Linear(c.hiddenSize, numVHeads, bias: false)
        _inProjA.wrappedValue = Linear(c.hiddenSize, numVHeads, bias: false)
        _conv1d.wrappedValue = Conv1d(
            inputChannels: convDim, outputChannels: convDim, kernelSize: convKernel,
            groups: convDim, bias: false)
        _norm.wrappedValue = GatedRMSNorm(dimensions: headVDim, eps: c.rmsNormEps)
        _outProj.wrappedValue = Linear(valueDim, c.hiddenSize, bias: false)
        _aLog.wrappedValue = MLXArray.zeros([numVHeads])
        _dtBias.wrappedValue = MLXArray.ones([numVHeads])
    }

    func callAsFunction(_ x: MLXArray, cache: LayerCache?) -> MLXArray {
        let (B, S) = (x.dim(0), x.dim(1))
        let single = cache as? LinearCache
        let batch = cache as? BatchLinearCache

        let qkv = inProjQKV(x)
        let z = inProjZ(x).reshaped(B, S, numVHeads, headVDim)
        let b = inProjB(x)
        let a = inProjA(x)

        // Short causal convolution over the last `convKernel` positions. The
        // cache supplies the inputs that came before this call.
        let convState = batch?.conv ?? single?.conv ?? MLXArray.zeros([B, convKernel - 1, convDim], dtype: x.dtype)
        let convInput = concatenated([convState, qkv], axis: 1)
        let convOut = silu(conv1d(convInput))

        let pieces = split(convOut, indices: [keyDim, 2 * keyDim], axis: -1)
        var q = pieces[0].reshaped(B, S, numKHeads, headKDim)
        var k = pieces[1].reshaped(B, S, numKHeads, headKDim)
        let v = pieces[2].reshaped(B, S, numVHeads, headVDim)

        // L2-normalize q and k, and fold the 1/sqrt(Dk) readout scale into q.
        let invScale = 1 / Float(headKDim).squareRoot()
        let ones = MLXArray.ones([headKDim], dtype: q.dtype)
        q = (invScale * invScale) * MLXFast.rmsNorm(q, weight: ones, eps: 1e-6 * invScale * invScale)
        k = invScale * MLXFast.rmsNorm(k, weight: ones, eps: 1e-6 * invScale * invScale)
        if numVHeads > numKHeads {
            q = repeated(q, count: numVHeads / numKHeads, axis: 2)
            k = repeated(k, count: numVHeads / numKHeads, axis: 2)
        }

        // Per-token, per-head decay g in (0, 1) and write strength beta in (0, 1).
        let g = exp(-exp(aLog.asType(.float32)) * softplus(a + dtBias))
        let beta = sigmoid(b)

        let state = batch?.recurrent ?? single?.recurrent ?? MLXArray.zeros([B, numVHeads, headVDim, headKDim], dtype: .float32)
        var y: MLXArray
        var newState: MLXArray
        var snapshots = [(MLXArray, MLXArray)]()
        let record = single?.recordSnapshots ?? false
        if gatedDeltaUseKernel {
            let history: MLXArray?
            (y, newState, history) = gatedDeltaMetal(
                q: q, k: k, v: v, g: g, beta: beta, state: state, saveHistory: record)
            if let history {
                // After token t the conv window is convInput[t+1 ..< t+convKernel].
                snapshots = (0 ..< S).map { t in
                    (convInput[0..., (t + 1) ..< (t + convKernel), 0...], history[t])
                }
            }
        } else {
            let states: [MLXArray]
            (y, newState, states) = gatedDeltaOps(q: q, k: k, v: v, g: g, beta: beta, state: state)
            if record {
                snapshots = states.enumerated().map { t, s in
                    (convInput[0..., (t + 1) ..< (t + convKernel), 0...], s)
                }
            }
        }

        let newConv = convInput[0..., (-(convKernel - 1))..., 0...]
        single?.update(conv: newConv, recurrent: newState, count: S, snapshots: snapshots)
        batch?.update(conv: newConv, recurrent: newState, count: S)

        y = norm(y, gate: z)
        return outProj(y.reshaped(B, S, valueDim))
    }
}

Around the recurrence:

  • Projections. in_proj_qkv produces queries, keys and values together; in_proj_z a gate for the output; in_proj_a and in_proj_b the decay and write-strength inputs.
  • Short convolution. Before the recurrence, q, k and v pass through a depthwise causal convolution with 4 taps: each channel becomes a learned mix of its last 4 values. This gives the layer cheap access to the immediately preceding tokens. During decode, the last 3 inputs must be remembered, so they are part of the cache alongside S.
  • Normalization. q and k are L2-normalized per head, and the 1/√Dk readout scale is folded into q. The code uses rmsNorm with a rescaled epsilon, because RMS norm is L2 norm divided by √Dk.
  • Heads. In the tiny MoE test model there are more value heads than key heads, so q and k are repeated to match; the 0.8B model has 16 of each.
  • Output. The result is RMS-normalized and multiplied by silu(z) in float32, then projected back to the hidden size.

The cache, and why it cannot rewind

code/Sources/Inference/LayerCache.swiftswift
/// State of one Gated DeltaNet layer: the last `kernel - 1` inputs of the
/// causal convolution, plus the `[B, Hv, Dv, Dk]` recurrent matrix.
///
/// The recurrent matrix is a running sum, so tokens cannot be subtracted
/// back out. To support `trim`, the layer can record a snapshot after every
/// token of a step (`recordSnapshots`), and `trim` restores one of them.
public final class LinearCache: LayerCache {
    public private(set) var offset = 0
    var conv: MLXArray?
    var recurrent: MLXArray?
    public var recordSnapshots = false
    var snapshots: [(conv: MLXArray, recurrent: MLXArray)] = []

    public init() {}

    func update(conv: MLXArray, recurrent: MLXArray, count: Int, snapshots: [(MLXArray, MLXArray)]) {
        self.conv = conv
        self.recurrent = recurrent
        self.snapshots = snapshots
        offset += count
    }

    public var state: [MLXArray] { [conv, recurrent].compactMap { $0 } }

    public func trim(_ count: Int) {
        guard count > 0 else { return }
        // snapshots[i] is the state after token i of the last step.
        precondition(count < snapshots.count, "can only trim tokens from the last recorded step")
        let restored = snapshots[snapshots.count - 1 - count]
        conv = restored.conv
        recurrent = restored.recurrent
        offset -= count
        snapshots = []
    }
}

An attention cache can forget the last n tokens by moving its write position back. S cannot: each token's contribution has been decayed and mixed into every entry, and there is no way to subtract it out. That is why Lesson 14's prompt cache matches whole entries only. Speculative decoding (Lesson 19) needs to undo rejected draft tokens, so the cache can optionally keep a snapshot of the state after each token of a step, and trim restores one of them.

A custom Metal kernel

The ops version launches a compiled kernel per token per layer, and each launch reads S from memory and writes it back: 1 MB per layer per token for the 0.8B model. During a 512-token prefill that is 512 round trips per layer. The kernel below keeps S in registers for the whole sequence instead:

code/Sources/Inference/GatedDelta.swiftswift
/// The same recurrence as a Metal kernel. Each SIMD group owns one row of
/// one head's state and keeps it in registers for all `T` tokens, so the
/// state is read from and written to memory once per call, not once per token.
private let gatedDeltaKernel = MLXFast.metalKernel(
    name: "gated_delta_step",
    inputNames: ["q", "k", "v", "g", "beta", "state_in", "T"],
    outputNames: ["y", "state_out", "history"],
    source: """
        auto n = thread_position_in_grid.z;
        auto b_idx = n / Hv;
        auto h_idx = n % Hv;
        constexpr int n_per_t = Dk / 32;

        auto q_ = q + b_idx * T * Hv * Dk + h_idx * Dk;
        auto k_ = k + b_idx * T * Hv * Dk + h_idx * Dk;
        auto v_ = v + b_idx * T * Hv * Dv + h_idx * Dv;
        y += b_idx * T * Hv * Dv + h_idx * Dv;

        auto dk_idx = thread_position_in_threadgroup.x;
        auto dv_idx = thread_position_in_grid.y;

        auto i_state = state_in + (n * Dv + dv_idx) * Dk;
        auto o_state = state_out + (n * Dv + dv_idx) * Dk;

        float state[n_per_t];
        for (int i = 0; i < n_per_t; ++i) {
          state[i] = static_cast<float>(i_state[n_per_t * dk_idx + i]);
        }

        auto g_ = g + b_idx * T * Hv;
        auto beta_ = beta + b_idx * T * Hv;

        for (int t = 0; t < T; ++t) {
          float kv_mem = 0.0f;
          for (int i = 0; i < n_per_t; ++i) {
            auto s_idx = n_per_t * dk_idx + i;
            state[i] = state[i] * g_[h_idx];
            kv_mem += state[i] * k_[s_idx];
          }
          kv_mem = simd_sum(kv_mem);

          auto delta = (v_[dv_idx] - kv_mem) * beta_[h_idx];

          float out = 0.0f;
          for (int i = 0; i < n_per_t; ++i) {
            auto s_idx = n_per_t * dk_idx + i;
            state[i] = state[i] + k_[s_idx] * delta;
            out += state[i] * q_[s_idx];
          }
          out = simd_sum(out);
          if (thread_index_in_simdgroup == 0) {
            y[dv_idx] = static_cast<InT>(out);
          }
          q_ += Hv * Dk;
          k_ += Hv * Dk;
          v_ += Hv * Dv;
          if (SaveHistory) {
            // history: [T, B * Hv, Dv, Dk], the state after token t.
            auto h_state = history + ((t * B * Hv + n) * Dv + dv_idx) * Dk;
            for (int i = 0; i < n_per_t; ++i) {
              h_state[n_per_t * dk_idx + i] = static_cast<StT>(state[i]);
            }
          }
          y += Hv * Dv;
          g_ += Hv;
          beta_ += Hv;
        }
        for (int i = 0; i < n_per_t; ++i) {
          o_state[n_per_t * dk_idx + i] = static_cast<StT>(state[i]);
        }
        """
code/Sources/Inference/GatedDelta.swiftswift
/// Returns outputs `[B, T, Hv, Dv]`, the final state, and, when
/// `saveHistory` is set, the state after every token `[T, B, Hv, Dv, Dk]`.
func gatedDeltaMetal(
    q: MLXArray, k: MLXArray, v: MLXArray, g: MLXArray, beta: MLXArray, state: MLXArray,
    saveHistory: Bool = false
) -> (MLXArray, MLXArray, MLXArray?) {
    let (B, T, H, Dk) = (q.dim(0), q.dim(1), q.dim(2), q.dim(3))
    let Dv = v.dim(3)
    let out = gatedDeltaKernel(
        [q, k, v, g, beta, state, T],
        template: [("InT", q.dtype), ("StT", state.dtype), ("Dk", Dk), ("Dv", Dv), ("Hv", H),
                   ("B", B), ("SaveHistory", saveHistory)],
        grid: (32, Dv, B * H),
        threadGroup: (32, 4, 1),
        outputShapes: [[B, T, H, Dv], state.shape, saveHistory ? [T] + state.shape : [1]],
        outputDTypes: [q.dtype, state.dtype, state.dtype])
    return (out[0], out[1], saveHistory ? out[2] : nil)
}

How the work is split: the grid launches one SIMD group of 32 threads per row of S per head per batch element. Each thread holds Dk / 32 entries of its row in registers. For each token the threads decay their entries, compute their share of S k and combine it with simd_sum, apply the delta update, and compute their share of S q the same way. S is read once at the start and written once at the end. The optional history output writes the state after every token; Lesson 19 uses it for rollback.

Gated full attention

code/Sources/Inference/Qwen35.swiftswift
/// Full attention with an output gate: `q_proj` produces queries and a
/// per-channel gate, and the attention output is multiplied by
/// `sigmoid(gate)` before `o_proj`. RoPE rotates only the first `ropeDims`
/// dimensions of each head.
final class GatedAttention: Module {
    let heads: Int
    let kvHeads: Int
    let headDim: Int
    let ropeDims: Int
    let ropeTheta: Float
    let scale: Float

    @ModuleInfo(key: "q_proj") var qProj: Linear
    @ModuleInfo(key: "k_proj") var kProj: Linear
    @ModuleInfo(key: "v_proj") var vProj: Linear
    @ModuleInfo(key: "o_proj") var oProj: Linear
    @ModuleInfo(key: "q_norm") var qNorm: RMSNorm
    @ModuleInfo(key: "k_norm") var kNorm: RMSNorm

    init(_ c: Qwen35Config) {
        heads = c.numAttentionHeads
        kvHeads = c.numKeyValueHeads
        headDim = c.headDim
        ropeDims = c.ropeDims
        ropeTheta = c.ropeParameters.ropeTheta
        scale = 1 / Float(headDim).squareRoot()
        _qProj.wrappedValue = Linear(c.hiddenSize, heads * headDim * 2, bias: false)
        _kProj.wrappedValue = Linear(c.hiddenSize, kvHeads * headDim, bias: false)
        _vProj.wrappedValue = Linear(c.hiddenSize, kvHeads * headDim, bias: false)
        _oProj.wrappedValue = Linear(heads * headDim, c.hiddenSize, bias: false)
        _qNorm.wrappedValue = RMSNorm(dimensions: headDim, eps: c.rmsNormEps)
        _kNorm.wrappedValue = RMSNorm(dimensions: headDim, eps: c.rmsNormEps)
    }

    func callAsFunction(_ x: MLXArray, cache: LayerCache?) -> MLXArray {
        let (B, L) = (x.dim(0), x.dim(1))

        let qg = qProj(x).reshaped(B, L, heads, 2 * headDim)
        let parts = split(qg, parts: 2, axis: -1)
        let gate = parts[1].reshaped(B, L, heads * headDim)

        let q = qNorm(parts[0]).transposed(0, 2, 1, 3)
        let k = kNorm(kProj(x).reshaped(B, L, kvHeads, headDim)).transposed(0, 2, 1, 3)
        let v = vProj(x).reshaped(B, L, kvHeads, headDim).transposed(0, 2, 1, 3)

        let out = attend(q: q, k: k, v: v, cache: cache, scale: scale) { [ropeDims, ropeTheta] x, offset in
            MLXFast.RoPE(x, dimensions: ropeDims, traditional: false, base: ropeTheta, scale: 1, offset: offset)
        }
        .transposed(0, 2, 1, 3).reshaped(B, L, heads * headDim)
        return oProj(out * sigmoid(gate))
    }
}

Two differences from Qwen3's attention. q_proj is twice as wide and produces both the queries and a per-channel output gate; the attention output is multiplied by sigmoid(gate) before o_proj, letting the model switch a head's contribution off. And RoPE rotates only the first quarter of each 256-dimensional head (partial_rotary_factor 0.25, so 64 dimensions); the rest carry content without position. Qwen3.5's config describes a multimodal rotary scheme (mRoPE) for images and video; for text all its position streams are equal, and it reduces to ordinary RoPE on those 64 dimensions.

Loading Qwen3.5

code/Sources/Inference/Qwen35Loader.swiftswift
/// Loads the text model (and MTP head) from an original Hugging Face
/// Qwen3.5 checkpoint, optionally quantizing it on the fly.
public func loadQwen35(
    from directory: URL, withMTP: Bool = true, quantizeBits: Int? = 4, groupSize: Int = 64
) throws -> Qwen35Model {
    let config = try Qwen35Config.load(from: directory)
    let model = Qwen35Model(config, withMTP: withMTP)

    let files = try FileManager.default.contentsOfDirectory(at: directory, includingPropertiesForKeys: nil)
        .filter { $0.pathExtension == "safetensors" }
    guard !files.isEmpty else { throw LoadError.noWeights(directory) }

    var weights = [String: MLXArray]()
    for file in files {
        for (name, array) in try loadArrays(url: file) {
            if let renamed = sanitize(name, withMTP: withMTP) {
                weights[renamed] = array
            }
        }
    }

    if config.tieWordEmbeddings { weights["lm_head.weight"] = nil }
    stackExperts(&weights)

    for (name, array) in weights {
        // PyTorch stores depthwise conv weights as [out, 1, kernel];
        // MLX wants [out, kernel, 1].
        if name.hasSuffix("conv1d.weight") && array.dim(-1) != 1 {
            weights[name] = array.swappedAxes(1, 2)
        }
        // Qwen3.5 RMSNorms scale by (1 + w) and store only w. MLX's RMSNorm
        // scales by w, so add the 1 back once at load time.
        if isShiftedNorm(name) {
            weights[name] = array + 1
        }
    }

    try model.update(parameters: ModuleParameters.unflattened(weights), verify: [.all])

    if let bits = quantizeBits {
        quantize(model: model) { path, module in
            // Quantize every matrix whose input width splits into whole
            // groups. Anything else (norms, conv, A_log, tiny test models)
            // stays in bf16.
            let inputs: Int
            switch module {
            case let m as Linear: inputs = m.weight.dim(-1)
            case let m as SwitchLinear: inputs = m.weight.dim(-1)
            case let m as Embedding: inputs = m.weight.dim(-1)
            default: return nil
            }
            return inputs % groupSize == 0 ? (groupSize, bits, .affine) : nil
        }
    }
    eval(model)
    return model
}

private func isShiftedNorm(_ name: String) -> Bool {
    guard !name.contains("linear_attn.norm") else { return false }
    return ["input_layernorm.weight", "post_attention_layernorm.weight", "q_norm.weight",
            "k_norm.weight", "model.norm.weight", "mtp.norm.weight",
            "pre_fc_norm_embedding.weight", "pre_fc_norm_hidden.weight"]
        .contains { name.hasSuffix($0) }
}

Every difference from Qwen3 is a trap that produces a working but wrong model:

  • Names. The checkpoint is a vision-language model: text weights sit under model.language_model. and the vision tower under model.visual., which is skipped.
  • Conv weights are stored PyTorch-style as [out, 1, kernel]; MLX wants [out, kernel, 1].
  • Norms. Qwen3.5's RMSNorms multiply by (1 + w) and store only w, which is near zero. MLX's RMSNorm multiplies by w. Adding 1 at load time fixes it, for every norm except the gated norm inside linear attention, which uses w directly. Forget this and the model loads, runs, and is quietly broken.
  • The MTP head. The weights under mtp. are kept. The popular pre-quantized community conversions of Qwen3.5 drop them (their index has zero mtp keys), so this loader starts from the original bfloat16 checkpoint and quantizes every matrix whose width divides into groups of 64 itself. Loading 0.8B this way peaks at about 2 GB of memory before settling at about 0.5 GB.

Parity against mlx-lm for the bfloat16 model: the same top token at every position, with differences up to 0.58 at logits around 23, both for full prefill and for token-by-token decoding through the caches.

Lesson in one breath

Gated DeltaNet keeps a per-head matrix S that it decays, corrects toward each new key-value pair, and reads with each query, so per-token cost and memory are constant in context length. Each layer also has a 4-tap causal convolution whose last 3 inputs are cached. A Metal kernel that keeps S in registers across tokens prefills about 3× faster than the op-by-op version. The full-attention layers add an output gate and rotate only a quarter of each head. Loading requires transposing conv weights, adding 1 to most norm weights, and keeping the MTP head.
